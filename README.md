# Second Look: SIP Pause or Reduction

Clickable prototype for Produscope 2026 (Team UpForge Consulting).

When an investor taps **Pause** on a SIP, Second Look asks why, shows personalised context for that reason, and leaves the final decision with the investor. A deterministic engine calculates every number. Template-based "AI" wording explains them.

```bash
npm install
npm run dev      # local
npm run build    # static build → dist/ (Vercel auto-detects Vite)
npm test         # engine + guardrail unit tests
npm run e2e      # Playwright flow tests
```

See `PLAN.md` for scope, numbers and screen spec.
